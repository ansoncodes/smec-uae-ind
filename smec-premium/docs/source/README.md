# Source documents

Machine conversions of the three 2026 handover documents, kept here so the
spec can be grepped, quoted with line numbers and diffed when a new version
arrives. The `.docx` files in the parent folder remain the originals — if the
two ever disagree, the `.docx` wins.

Converted with a plain docx→markdown pass (headings, paragraphs, tables); no
wording was changed, and images and styling were dropped.

| File | Owns |
| --- | --- |
| `SMEC_Website_Content_Master_2026_V3_DEEP_CONTENT.md` | Page inventory, URLs, titles/meta, H1s, answer blocks, FAQs |
| `SMEC_Website_Technical_SEO_Master_2026_FINAL_HANDOFF.md` | Architecture, schema, indexation, redirects, performance, a11y, security, analytics |
| `SMEC_Website_Developer_Handover_Brief_2026.md` | Build decisions, assets, integrations, responsibilities, UAT, acceptance |
