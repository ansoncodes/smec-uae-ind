# Pipelines & Terminals

**Connect remote assets to the control room.**

SCADA, RTU and electrical control integration for pipeline infrastructure and terminal operations.

### Pipeline SCADA

Remote monitoring and control

- SCADA and RTU integration
- Telemetry and communication links
- Alarm and event management

### Station Controls

Local automation and electrical systems

- Pump and valve control panels
- VFD/MCC and power distribution
- Instrumentation and shutdown interfaces

### Terminal Operations

Site-level integration

- Tank and process monitoring interfaces
- Control room HMI and reporting
- Brownfield upgrade and commissioning
