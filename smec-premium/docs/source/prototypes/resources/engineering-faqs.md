# Engineering FAQs

Clear answers to common technical and project questions.

## Authored reference content (in prototype)

### What information should be included in an industrial automation RFQ?

Share the existing control architecture, process description, I/O list, electrical drawings, required interfaces, site conditions and project schedule. For a retrofit, include OEM and model details, fault history and available shutdown windows.

### What is the difference between FAT and SAT?

Factory Acceptance Testing checks the assembled system against an agreed test procedure before dispatch. Site Acceptance Testing confirms installation, interfaces and functionality in the actual operating environment.

### Can an obsolete PLC be replaced without replacing all field instruments?

Often, yes. Compatibility depends on signal types, wiring condition, communication protocols, safety requirements and migration strategy. An I/O survey and interface review should come first.

### What should be checked before a rig reactivation?

Review power generation, switchgear, drives, PLC/HMI backups, instrumentation, protective trips, emergency systems, alarms and critical interlocks. Plan functional testing and commissioning around the intended return-to-service scope.

### When does an offshore system require hazardous-area equipment?

Equipment selection depends on the formal area classification, gas group, temperature class, installation method and applicable project standards. An offshore location alone does not establish the required protection method.

### What information is needed to assess an SCR or VFD upgrade?

Provide motor nameplate data, drive topology, electrical single-line diagrams, duty cycle, braking requirements, cooling arrangement, cable details and available footprint.

### Can SCADA connect remote pipeline stations?

Yes. RTUs or PLCs can exchange data with a central SCADA system through suitable communications infrastructure. The design should address network availability, cybersecurity, time stamping and safe local control.

### How do we start an engineering enquiry with SMEC?

Send the application, site location, scope of supply, existing equipment details and relevant drawings or specifications. The engineering team can review the available information and identify the next technical steps.
