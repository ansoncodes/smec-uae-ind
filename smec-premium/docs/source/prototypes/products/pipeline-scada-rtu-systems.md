## What is Pipeline SCADA & RTU Systems? _(hidden in prototype)_

Pipeline SCADA must connect dispersed stations without losing clarity about command authority, communications status or alarm priority. The engineering scope can bring RTUs, metering, valves, pump/compressor stations and supervisory systems into a coherent architecture.


## How it works

**Remote stations**

RTUs collect pipeline pressure, flow, metering, valve and equipment data at geographically distributed stations.

**Supervisory layer**

SCADA provides operator displays, alarms, historical trends and controlled remote commands.

**Communications**

Latency, outages, redundancy, time synchronisation and store-and-forward requirements shape the telemetry design.

**Cyber and safety**

Remote-control authority, network segregation and fail-safe local operation are essential; leak detection is a separate engineered function.


## Key components

- RTU/PLC panels. An RTU acquires remote station measurements and status, timestamps events and exchanges authorised commands with SCADA while preserving local control on link loss.
- Remote I/O. The remote i/o is selected for the equipment, operating duty and site conditions.
- Telemetry gateways. The telemetry gateways is selected for the equipment, operating duty and site conditions.
- Pump and compressor interfaces. The pump and compressor interfaces is selected for the equipment, operating duty and site conditions.
- Valve stations. Valve actuation and position feedback must follow the approved process control and fail-safe philosophy, including loss-of-power behaviour.
- Alarm/event logging. Alarm thresholds, priorities, delays and operator actions must be documented to avoid nuisance alarms and missed critical events.
- Historian. The historian is selected for the equipment, operating duty and site conditions.
- SCADA HMI. SCADA consolidates remote station measurements, alarms, trends and supervisory commands; local protective functions remain in field controls.
- Redundant communication options. Protocols, command authority, network availability, loss-of-link response and cybersecurity boundaries must be agreed for every equipment interface.

## FAQs

**Is SCADA a leak detection system?**

No. SCADA provides data and controls; leak detection requires a separately defined detection methodology.

**Can mixed-vendor RTUs be integrated?**

Often, subject to protocols, licensing, data mapping and cybersecurity requirements.

**What is required for an RFQ?**

Station count, tag lists, telecoms details, existing RTUs, network diagram and control-room scope.
