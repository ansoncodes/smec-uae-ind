# Scaffold images - TEMPORARY PLACEHOLDERS

These photographs are stand-ins so the layout can be judged with real imagery.
They are **not** SMEC assets. Replace each one with a client photograph, then delete
its entry in `lib/scaffold.ts` and the file here. Every usage in code is marked
`SCAFFOLD` and the rendered `<img>` carries `data-scaffold="<id>"`.
